Application Security / Fraud Alerting

GramKavach

Team Project · ADVAYA 2.0 Hackathon
Context
Digitally vulnerable and rural users are often assumed to have reliable connectivity, strong digital literacy and ready access to security tools — an assumption that leaves them more exposed to fraud and unauthorized account activity.
Approach
Built collaboratively in 24 hours at the ADVAYA 2.0 national hackathon: a full-stack alert and verification layer (React/TypeScript/Vite frontend, Supabase/PostgreSQL backend) that walks suspicious financial activity through detection, alerting, user verification and escalation.
Security Focus
Database-level access control via Row Level Security, an offline-first mindset for low-connectivity users, and a human verification/escalation step rather than automated account actions.
Result
A working hackathon prototype demonstrating the full detect → alert → verify → escalate → respond flow, built and shipped within the 24-hour window. Explicitly a proof of concept, not a production banking security system.

ReactTypeScriptViteSupabasePostgreSQLRow Level Security
